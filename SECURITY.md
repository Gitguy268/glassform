# Security

glassform runs in the browser and has no server component. Security issues most likely involve the DOM snapshot path, the HTML-in-Canvas integration or the SVG filters the CSS tier injects.

## Reporting

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Gitguy268/glassform/security/advisories/new), not in a public issue. I aim to reply within a week.

## Supported versions

Only the latest commit on `main` is supported until a release is published.
