# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep criticism about the work. Harassment of any kind is not accepted.

To report a problem, contact the maintainer through their GitHub profile, [@Gitguy268](https://github.com/Gitguy268). Reports are handled privately.
